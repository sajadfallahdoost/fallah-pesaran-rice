## ۴) مشکلات کشف‌شده و اصلاحات کد

### مشکلات

1. sitemap فقط صفحهٔ اول محصولات را می‌گرفت و `lastmod` نداشت.
2. محصولات نمونه با وجود `noindex` هنوز Product/Offer JSON-LD می‌فرستادند.
3. `seo_title` / `seo_description` تنظیمات فروشگاه در صفحهٔ اصلی استفاده نمی‌شد.
4. دربارهٔ ما metadata ثابت بود و `/info/about` تکراری crawl می‌شد.
5. فیلتر/مرتب‌سازی فقط به canonical متکی بود و `noindex` نداشت.
6. بخش محتوای آموزشی برای رقابت خوشه‌های غیربرند وجود نداشت.
7. فوتر لینک مستقیم به `/contact` و بخش راهنما نداشت.

### تغییرات انجام‌شده (لوکال؛ بدون commit/deploy)

| حوزه | فایل‌ها |
|---|---|
| sitemap صفحه‌بندی + lastmod + guides | `frontend/src/app/sitemap.ts` |

| metadata خانه/فروشگاه/دسته/درباره | `page.tsx`, `shop/page.tsx`, `category/[slug]/page.tsx`, `about/page.tsx` |

## ۵) برنامهٔ محتوا و بازاریابی ۳۰ / ۶۰ / ۹۰ روز

### روز ۱–۳۰ (پایهٔ ایندکس و اعتماد)

- انتشار دامنهٔ HTTPS + ارسال sitemap در Search Console.
- جایگزینی محصولات نمونه با محصولات واقعی (رقم، وزن، قیمت، عکس واقعی، alt).
- تکمیل فیلدهای سئوی دسته/محصول در ادمین.
- تأیید یا بازنویسی صفحات سیاست (`/info/*`) و برداشتن برچسب پیش‌نویس.
- انتشار/بازبینی ۶ راهنمای فعلی؛ لینک از اینستاگرام/تلگرام به `/guides` و `/category/rice`.
- ثبت کسب‌وکار در نقشه‌ها با نشانی و تلفن تأییدشده (نه ادعای جعلی).

### روز ۳۱–۶۰ (عمق تجاری)

- افزودن ارقام واقعی پرتقاضا (مثلاً هاشمی/طارم/دمسیاه/فجر) فقط اگر موجودی واقعی دارید.
- یک راهنمای مقایسه‌ای «مصرف روزانه در برابر مهمانی» با لینک به ۲–۳ PDP.
- تصمیم مالک دربارهٔ ارسال رایگان، عمده، قسطی؛ در صورت تأیید، یک صفحهٔ شفاف نه شعار خالی.
- جمع‌آوری عکس مزرعه/انبار/بستهٔ واقعی (بدون معرفی تصویر تولیدی به‌عنوان عکس واقعی).

### روز ۶۱–۹۰ (برند و لینک معتبر)

- صفحهٔ دربارهٔ ما با نقش تأییدشدهٔ افراد (در صورت تمایل مالک).
- همکاری محتوایی غیر اسپم با فروشگاه‌های محلی/رسانه‌های خوراکی؛ مهمان‌نوشته یا معرفی متقابل فقط با منبع واقعی.
- پایش برند در برابر fallah.shop؛ در صورت سردرگمی کاربر، باکس تمایز در about/contact.
- بهینه‌سازی عناوین بر اساس CTR واقعی Search Console (نه حدس).

مسیر تبدیل پیشنهادی: راهنما → دسته → محصول → تماس/سبد → پرداخت. رویدادهای قابل‌سنجش: مشاهدهٔ PDP، افزودن به سبد، شروع checkout، پرداخت موفق، کلیک تماس/تلگرام.

## ۶) Search Console و تحلیل

پس از فعال‌شدن دامنه (هنوز در این مأموریت متصل نشده):

1. تأیید مالکیت با DNS TXT یا فایل HTML روی همان origin نهایی.
2. ارسال `https://fallah-rice.ir/sitemap.xml`.
3. بررسی Coverage/Indexing برای `/`, `/category/*`, `/product/*`, `/guides/*`.
4. پایش جداگانهٔ عبارت‌های برند و غیربرند.
5. در صورت افزودن Analytics/Matomo/Plausible: بدون ارسال شمارهٔ کارت یا دادهٔ حساس؛ رویدادها مطابق امکانات واقعی پروژه.

## ۷) آزمایش‌های انجام‌شده و محدودیت‌ها

| آزمایش | نتیجه |
|---|---|
| `npx next typegen && npm run typecheck` | موفق |
| `npm run lint` | موفق |
| `npm run build` (با Django روی `:8010`) | موفق؛ مسیرهای `/guides` و ۶ مقاله در خروجی بیلد |
| `GET /robots.txt` لوکال | Allow/Disallow درست؛ Host و Sitemap از `SITE_URL` |
| `GET /sitemap.xml` لوکال | راهنماها + lastmod؛ دسته‌ها با lastmod؛ محصولات نمونه غایب |
| متادیتای خانه/دسته/راهنما | title، description، canonical در HTML |
| `/shop?sort=price_asc` | `noindex, follow` + canonical به `/shop` |
| `/info/about` | redirect دائمی ۳۰۸ به `/about` |
| PDP نمونه | `noindex` و **بدون** Product/Offer JSON-LD |
| JSON-LD خانه | `Store` + `WebSite` |
| دامنهٔ نهایی / Search Console | انجام نشد (DNS/دسترسی) |
| Lighthouse کاربران واقعی | انجام نشد |

محدودیت‌ها: در محیط لوکال `SITE_URL` برابر `localhost:3010` است و پس از تنظیم `PUBLIC_BASE_URL` باید فرانت دوباره build شود. کاتالوگ فعلی عمدتاً نمونه است؛ قیمت‌های رقیب اسنپ‌شات‌اند؛ حجم جست‌وجوی رسمی در دست نیست.

## ۸) تصمیم‌ها و اطلاعات لازم از مالک

1. آیا با بازرگانی فلاح / fallah.shop نسبتی دارید یا باید تمایز صریح نوشته شود؟
2. نقش و متن تأییدشده برای «محمود فلاح دوست» و «سجاد فلاح دوست».
3. محصولات واقعی، قیمت، موجودی، رقم، منطقه، سال برداشت، عکس غیرتولیدی.
4. ارسال رایگان، عمده، قسطی، خرید مستقیم از کشاورز، تضمین اصالت: کدام‌ها واقعاً ارائه می‌شوند؟
5. ساعات پاسخ‌گویی، تعرفهٔ نهایی ارسال، مهلت مرجوعی.
6. تأیید نهایی متون سیاست و برداشتن `requires_owner_review`.
7. دسترسی Search Console و ابزار تحلیل پس از DNS.
